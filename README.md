# Mac 桌面待办日历

在 Mac 桌面用透明背景显示每天的待办，在 App 主窗口查看全部任务和统计。项目目前处于需求讨论阶段。

## 已确认的功能

- 用户可以配置桌面日历，点击切换日、周、月视图。
- 在桌面日历上点击日期，为该日期新增待办。
- 点击任务标题，在桌面编辑该待办。
- 每项待办可设置优先级和截止时间。
- 新增跨天任务时，起止日期都计入显示范围，每天分别记录完成状态。
- 跨天任务共用标题、优先级和截止时间。在任意一天编辑这些字段，修改同步到该任务覆盖的所有日期。只有完成状态按天单独记录。
- 点击勾选框只切换当天的完成状态，日、周、月视图同步显示结果。
- App 内提供全部待办的总览和统计。

## 桌面显示

日历默认贴在桌面，打开其他应用窗口时，重叠部分会被自然盖住。开启「置顶」后，日历显示在普通应用窗口上方。关闭「置顶」即可恢复桌面显示。

外观参考用户提供的桌面日历截图，采用紧凑的圆角卡片布局，在月视图中突出显示当天日期。

## 总览与完成进度

每项任务在总览中只占一行。进度显示已勾选天数和任务覆盖的总天数。每次勾选计入对应日期的完成统计，所有日期都勾选后，整项任务才算完成。

例如，“准备评审”从 11 月 23 日持续到 26 日，共四天。仅勾选 24 日时，总览显示“已完成 1/4 天”。四天全部勾选后，任务显示“已完成 4/4 天”，计入已完成任务数。
