# dayfold · 折历

折历是一款原生 macOS 桌面待办日历。它可以缩成一条可拖动的窄栏，展开后即可查看、编辑和勾选每天的任务。首版采用 SwiftUI 与 AppKit，任务保存在本机。

## 下载与安装

**[下载折历 v0.1.1（macOS 通用 DMG）](https://github.com/liangxiaoLv/dayfold/releases/download/v0.1.1/Dayfold-0.1.1-macOS-universal.dmg)**

适用于 macOS 14 及以上版本，支持 Apple 芯片和 Intel Mac。

1. 双击下载的 DMG，将「折历」拖到旁边的「Applications（应用程序）」文件夹。
2. 从「应用程序」打开「折历」，即可在桌面查看本周的待办。

v0.1.1 尚未经过 Apple 公证。若首次打开时提示无法验证开发者，确认安装包来自本仓库后，可前往「系统设置 → 隐私与安全性」选择「仍要打开」。[Apple 官方说明](https://support.apple.com/zh-cn/102445) · [版本说明与 SHA-256 校验值](https://github.com/liangxiaoLv/dayfold/releases/tag/v0.1.1)

## 已确认的功能

- 用户可以配置桌面日历，点击切换日、周、月视图。
- 在桌面日历上点击日期，为该日期新增待办。
- 点击任务标题，在桌面编辑该待办。
- 每项待办可设置低、中、高优先级，截止日期精确到日。
- 截止提醒默认关闭。单独开启后再选择几点几分，由 macOS 在截止日发送一次通知。
- 新增跨天任务时，起止日期都计入显示范围，每天分别记录完成状态。
- 跨天任务共用标题、优先级和截止时间。在任意一天编辑这些字段，修改同步到该任务覆盖的所有日期。只有完成状态按天单独记录。
- 点击勾选框只切换当天的完成状态，日、周、月视图同步显示结果。
- App 内提供全部待办的总览和统计。

## 桌面显示

日历默认贴在桌面，打开其他应用窗口时，重叠部分会被自然盖住。开启「置顶」后，日历显示在普通应用窗口上方。关闭「置顶」即可恢复桌面显示。

外观参考用户提供的桌面日历截图，采用紧凑的圆角卡片布局，在月视图中突出显示当天日期。

点击日历右上角的「缩小」会收成一行。拖动窄栏左侧的「折历」可让出桌面文件。松手时会记住窄栏的位置，再次缩小或重启后缩小时会回到那里。点击右侧「展开」即可恢复缩小前的日期、视图、大小和桌面位置。

## 占用范围与日历视图

桌面占用范围有整屏、半屏和四分之一屏三档。半屏可以选左半屏或右半屏。每一档都支持日、周、月三种视图，日程随可用宽度和高度重新排布。

- 日视图默认显示今天，只展示安排在所选日期的待办。以前日期的未完成项保留在原日期和任务总览中。
- 周视图默认显示本周七天的日程。例如选中右半屏和周视图时，七天共用右半屏的空间。通过日期范围下拉菜单可切到以前的周。
- 月视图默认显示本月，通过同样的日期选择入口可查看以前的月份。日视图也可以用此入口查看以前的日期。

### 布局与切换交互

四分之一屏可从四个角选择位置。占用范围按当前显示器的可用桌面计算。改变大小或位置时保留正在查看的日期范围。日期选择入口显示当前浏览的日期或范围，查看历史时可一键回到今天所在的日、周或月。

宽度充足时，周视图将七天并排。窄屏时按周内顺序分行，保留可读字号。任务较多时优先露出各天的日期和待办摘要，点击“还有 N 项”展开当天完整清单。切换布局时保留键盘焦点，以短过渡呈现变化，并尊重系统的减弱动态效果设置。

## 总览与完成进度

每项任务在总览中只占一行。进度显示已勾选天数和任务覆盖的总天数。每次勾选计入对应日期的完成统计，所有日期都勾选后，整项任务才算完成。

例如，“准备评审”从 11 月 23 日持续到 26 日，共四天。仅勾选 24 日时，总览显示“已完成 1/4 天”。四天全部勾选后，任务显示“已完成 4/4 天”，计入已完成任务数。


## 本机运行

在项目根目录运行以下命令，生成并打开本机架构的应用包。部署目标为 macOS 14 或更新版本。

```sh
./scripts/build-app.sh
open "dist/折历.app"
```

首次启动默认显示右半屏周视图，以周一为一周的开始。桌面右上角的布局按钮可切换大小和位置。点「总览」或在应用运行时点击 Dock 图标，可打开任务总览窗口。选择的视图、位置与置顶状态在下次启动时恢复。

任务文件保存在 `~/Library/Application Support/DeskCalendar/tasks.json`。开发时使用包含 Swift Testing 的 Swift 工具链运行 `./scripts/test.sh`。
