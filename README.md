# Mac 桌面待办日历

在 Mac 桌面用透明背景显示每天的待办，在 App 主窗口查看全部任务和统计。项目目前处于需求讨论阶段。

## 已确认的功能

- 用户可以配置桌面日历，点击切换日、周、月视图。
- 每项待办可设置优先级和截止时间。
- 新增跨天任务时，起止日期都计入显示范围，每天分别记录完成状态。
- 在任一视图勾选某天的待办，其他视图同步反映当天的完成状态。
- App 内提供全部待办的总览和统计。

例如，“准备评审”从 11 月 23 日持续到 26 日，连续四天都显示。勾选 24 日后，仅 24 日这一项完成。

## 待讨论

桌面日历是否支持直接新增和编辑待办，以及总览中如何呈现统计。
